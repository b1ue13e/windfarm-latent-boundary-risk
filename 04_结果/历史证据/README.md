# 保留证据

本目录保存 2026-11-11 文件整理中从旧稿件、旧包及临时目录分离的证据。它不是另一套现行稿件。

- `历史稿件证据`：各历史版本的数据、配置、来源代码、文献与审计。
- `历史门禁输入`：科学及数字门禁仍需的三份历史文本，不用于改稿或投稿。
- `TSTE历史审计`、`清理前现行检查记录`：历史检查及整理前的现行检查记录。
- `登记表修复及临时审计`：原运行缓存中实际具有调查和来源价值的材料。
- `旧压缩包唯一证据`：删除旧压缩包前提取、在已保留文件中未找到相同 SHA256 的数据和审计成员。

文件内容按原字节保存。数据与审计中的旧路径、哈希和数值不改写；维护工具通过 `02_公共资源/项目管理/目录迁移/path_map.json` 解析新位置。历史审计中的改稿前快照属于审计附件，予以保留。

原始实验结果、权重和科研审计主记录仍在 `01_研究尝试` 等原位置。TSTE 阅读文献移至 `02_公共资源/文献/TSTE当前稿件`。
