## 1. 结论：主要工况定位未变，但必须补充 C 的风险重分配

**VERIFIED：纳入完整五种子 C 后，中等风速、原标签稳态与功率下行关联的超限定位得到保留。** C 没有修复这些主要区域，反而在 [5,7.5) m/s、稳态和过去下行爬坡组中，五个种子均比 B 有更高的观测违约率。

**UNKNOWN：** 这些关联是否由某个天气、控制、图结构或校准漂移机制造成，以及新的历史校准是否能在未查看窗口通过原门槛。此次不计算或宣称新的校准收益。

## 5. 时间块归因有重排

| 策略 | 按自身违约率排序的前五个原生块 |
|---|---|
| B | 31、34、29、13、19 |
| C | **34、31、29、26、12** |
| D | 31、34、29、13、19 |
| D10 | 31、34、29、13、19 |

共同核心是 29、31、34。C 改善了若干原高块，另有 12、26 进入自己的前五；必须称为风险重分配，而不是所有高块不变。所有排序都是事后描述，不作选择校正后的显著性解释。

如果固定原 B 的高五块作为共同比较总体，B/C/D/D10 违约率分别为 **21.613% / 21.768% / 21.611% / 21.569%**；其余 30 块为 **8.991% / 9.152% / 8.985% / 8.969%**。这个共同总体不能被误叫作 C 自己的高五块。

原生块跨自然日、部分块有效覆盖低的限制不变；本次没有删掉高块或稀疏块以使模型通过。

## 7. 与重校准方案的连接及论断边界

主要定位支持一个可检验的下一步：先检验历史风速与已发生爬坡条件下的简单校准，避免继续只在原控制边界附近调整复杂模型。**这只是方案动机，不是新方法有效的证据。**

完整方案在 `experiments/E07_history_only_recalibration/PREREGISTRATION_DRAFT.md` / `protocol.json`：

- 原 B0 作为固定成本和风险基准；唯一主候选 B_WR；四原策略的全局/条件校准版本完整对照。
- 原 E04 测试期仅作为新未来窗口之前的历史校准，校准量在测试前冻结；新测试不参与偏移、阈值、分箱、支持规则或模型选择。
- q*=0.90、alpha=0.05、v_max=0.10、epsilon_C=epsilon_V=0 不变。主检验同时要求原 E04 与共享日块程序都通过，不通过则保留失败。
- 新 WTB 246—280 日数据当前未核实存在；方案是未执行草案，待采集规范及参数包清单绑定，不能把旧 35 日称作新确认性测试。

条件校准不自动带来漂移时间序列的无条件覆盖保证；这一区别与经典交换性校准和非交换性研究的前提一致。[CQR](https://proceedings.neurips.cc/paper/2019/file/5103c3584b063c431bd1268e9b5e76fb-Paper.pdf)，[非交换性边界](https://arxiv.org/abs/2202.13415)。本次没有计算新的校准策略数值。
