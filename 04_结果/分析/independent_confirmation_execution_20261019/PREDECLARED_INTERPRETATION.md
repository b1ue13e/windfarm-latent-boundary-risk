# 一次确认的预先解释规则

本文在2025尚未解封时写定解释边界，避免结果出来后倒换主要问题。完整数值程序和主要/次要族以已提交protocol为准；本文件不增加统计检验或候选。

| 实际情况 | 可以说什么 | 不能说什么 |
|---|---|---|
| 历史2%无选择 | 历史选择程序在该来源没有形成主要确认候选；报告NO_HISTORICAL_SELECTION | 到2025挑一个赢家冒充事前选择 |
| 历史有选择，但2025风险未通过 | 该冻结候选的跨年风险要求未确认 | 信息理论上无用、所有模型都不安全 |
| 风险通过、成本上界未通过 | 成本近优尚未确认，风险/成本分别报告 | 用点成本或不显著差异证明等价 |
| 冻结参照风险不合格 | 无法按预设的风险匹配参照认证充分性 | 只因更便宜而宣布充分 |
| 主要要求全部通过 | 当前来源/年份/五个固定实例、共同预测信息条件下的冻结策略得到有界支持 | 已证明真正最小、未来现场安全、PCC采购收益或所有场站通用 |
| 全q次要格找到充分或最小候选 | 报告预声明有限族上的事后能力与排除证据 | 把事后能力当作事前选择程序成功 |
| 只有5%或某敏感块长通过 | 报告对应敏感性边界，主结果不变 | 按结果改主要容限/块长 |
| schema/原字段冲突导致拒绝 | 源资格失败/数据缺口，保存失败 | 删掉冲突月份/机组后继续声称同一确认 |

年度均值与风险以有未来有功记录的风机区间为条件，不外推缺失目标；零/负功率保留。共同预测在该新场站本地历史训练，因此检验的是程序的跨来源适用性，不能宣称旧WTB权重零样本迁移。备用层新增信息的资源顺序以共同风速/有功预测器为条件，不是端到端传感器或计算最小性。

五个随机种子不是五份独立天气，也不是随机抽取算法总体的保证。日块界对季节/控制漂移仅作近似量化；单独变化块长不能证明覆盖。2025作为项目封存的外部确认年份，不声称公开数据对所有人历史上都未查看；本轮也不提供真实到达日志、计算延迟或现场安全认证。

允许之后基于2025探索改进，但任何此类程序必须另列版本，并取得新数据才能再次作独立确认。不得覆盖当前一次确认的负/零/失败结果。
