# 风电备用决策的信息价值与模型必要性：关键补证方案

日期：2026-10-18（Asia/Shanghai）。

**状态：研究设计草案，未执行；不是已激活的预注册，不认证任何科学结论。**

本方案依据 `SCIENTIFIC_CONTRACT.md`、`PROJECT.md` 与 `HISTORICAL_PROVENANCE_FREEZE_20261018.md`。不修改原始结果、旧失败记录、科学契约或 E04/E07；不启动模型、校准或数据采集。合格新数据、实际效应阈值、完整候选规格及统计功效仍待绑定。新研究不能补造历史来源。

## 1. 要回答的唯一主问题

在冻结的风电短缺目标和相同到达信息约束下，额外 SCADA 信号何时改变决策相关的条件尾部，何时只有状态识别改善而没有备用收益；据此能否在指定候选中选择风险合格的最简单策略？

待检验的竞争解释：

1. 基础风速历史已包含大部分决策相关信息；状态恢复主要重复这些信息。
2. 额外信号包含尾部信息，但当前状态表征没有保留或有效利用它。
3. 恢复了有用信息，但有限样本误差、校准偏差或部署输入变化抵消了收益。

三者目前均不能预设为已证实原因。表示是已有输入的函数，不凭空增加原始信息；表示价值与新增传感通道价值须分别检验。

## 2. 先固定评价对象

- 主条件：pitch 在部署中不可用；主预测步长 h=6；rho=10；Full 总体。h=1 为预定次要分析。
- 各信息条件及策略共享同一冻结点预测、目标坐标、固定机组队列和共同目标有效掩码。不可因某策略缺输入而删除其困难样本；输入缺失按预定回退处理。
- 主目标继续为逐机组 PSREI。不得将其称为已验证 PCC 采购成本。
- 若保留 PCC 应用结论，另建明确的聚合任务：先求净预测误差 `sum_i(yhat_i-y_i)`，再取正部；使用聚合目标单独校准备用。不能将逐机组短缺或分位数简单相加作为最优 PCC 策略。固定队列、缺目标处置及全部方法的聚合信息映射须事先声明。
- 机组主任务与 PCC 任务分别报告，PCC 结果不能救回主检验失败。
- 新研究的主有效掩码不按真实 pitch 工况筛选；ambiguous 样本保留在主决策总体。旧标签/旧掩码的结果只保留为独立诊断，不替换 E04 原定义。
- 原生状态标签在有效样本上可由风速区分，因此 AUROC/NMI 只能作描述。增加连续 pitch/状态诊断不自动生成新的决策证据。

## 3. 第一组证据：分开信息增量与表示增量（最高优先级）

先在 pitch-withheld 主条件完成下表。基础风速不局限于一个当前读数，应包含预先指定且已经到达的风速历史和可用标记。

| 对照 | 可用输入 | 决策方法 | 回答的问题 |
|---|---|---|---|
| A | 风速历史、到达/可用标记 | 强直接条件分位数 | 基础信息能做到什么程度 |
| B | A + 已到达有功、无功及其历史 | 与 A 相同的方法族和调参规则 | 新增信号是否有决策价值 |
| C | 与 B 完全相同 | B + 由相同输入产生的现有状态后验 | 显式状态表示是否优于直接利用相同信号 |
| D（诊断） | B + issue 时刻真实 pitch | 与 B 可比的直接条件分位数 | 当前 pitch 是否仍有可检测的额外价值 |

A/B 主对照只改变输入；保留十箱风速分位数作透明参照，同时使用一个能处理连续风速和历史的强直接估计器，避免将分箱粗糙误认为信息不足。可采用分位数树/提升树；正式实现前固定一种主估计器及验证预算，不在新测试上比较后择优。

B/C 对比固定原始输入、冻结预测、训练样本和历史校准机会。现有图/后验仅作比较探针，不新增图、MoE 或隐藏状态架构。不由某一个 B/C 结果推断所有函数类的最优风险。

无功及轨迹的单独贡献用预定删除对照定位；不展开所有通道组合。若 A/B 没有精确可辨的增量，先停止空间结构扩展。

D 使用 issue 时刻已有的实际 pitch，只改变可观测性；不得使用未来 pitch、未来 transition 或未来爬坡。D 是额外信息参考，不是数学上的信息价值上界，也不属于 pitch-withheld 可部署候选。

训练权限另行控制：

- 主部署轨道在训练、验证、测试均屏蔽 pitch 输入；若研究“从未记录 pitch”，状态标签也不得由 pitch 生成并进入训练。
- 如保留特权监督，单列历史 pitch 可用于监督的轨道，直接基线也获得相同的历史标签利用机会，例如简单状态分类器加直接分位数；与零特权轨道分开报告。
- 历史输入含 pitch、部署时才突然屏蔽的旧协议只作敏感性分析，不混入新主轨道。

## 4. 第二组证据：定位信息在哪一步失去决策价值

对同一测试坐标保存 A/B/C/D 的后验、分位数、备用动作、短缺、违约和成本。沿以下链条组织分析：

`状态诊断变化 -> 决策相关分位数变化 -> 备用动作变化 -> 实际配对损失变化`

- 状态诊断：相对于风速历史基线的 Brier/log loss 和标签恢复变化，旧 NMI 仅辅助展示。
- 尾部诊断：Q0.90 对应的测试 pinball loss、覆盖偏差及预定条件组结果；不能用未经验证的分位数点估计差证明真实尾部变化。pinball 与同一 newsvendor 损失的结果具有代数关联，不能算作两份独立证据。
- 动作诊断：备用增量分布、动作改变比例、额外备用投放位置；明确展示采购项与未覆盖短缺项，防止把增加备用后的少违约当作成本收益。
- 定位组：仅按已到达的风速及过去功率变化预先分组。真实 transition、未来下降事件只作事后描述，不作在线选择输入。
- 不从观察性分组直接推断空气动力学因果。若要保留额定饱和/延迟机制解释，必须独立给出实际使用的物理或统计规则、功率截断、通道时钟和对应动作轨迹。经验条件分位数与气动功率曲线分开命名。

解释规则：

| 结果组合 | 允许解释 |
|---|---|
| 状态诊断改善，尾部和成本未改善且区间足够窄 | 状态识别改善未转化为本任务的可检测决策价值 |
| B 优于 A，C 不优于 B | 额外信号有用，当前显式表示没有额外收益 |
| D 优于 B/C，而 B/C 不优于 A | 当前候选未恢复或利用真实 pitch 的潜在价值；不能判定唯一原因 |
| C 优于 B，且风险门禁通过 | 当前表示在指定同信息候选对照中有价值 |
| 区间较宽 | 信息不足以区分解释；不能写成无信息或等效 |

## 5. 第三组证据：信息条件下的模型选择边界

核心 A/B/C 对照明确后，再扩展到三个预先定义的信息条件：

1. 风速与 pitch 新鲜；
2. 所有相应通道共同延迟，10/20/30 min，60 min 单列压力端点；
3. pitch 全程不可用于部署，其他通道按到达信息可用。

每个条件内，候选共享信息权限；每个延迟条件校准只使用相同条件的历史验证数据。所有条件使用共同冻结预测与物理时刻总体，以隔离信息退化。另行采用随条件改变的预测器属于另一研究问题。

每个条件仅保留必要候选：透明规则或风速分箱、直接分位数及其历史重校准、现有表示比较器。未校准版本保留为对照；不能给复杂方法更多校准或调参机会。

保留原 E04 风险门槛 q*=0.90、alpha=0.05、v_max=0.10 和零成本/违约差容限。新场站须有自己的事前候选、基准和资源复杂度顺序，不能沿用旧 WTB 认证身份。

候选和比较在测试前全部冻结。若基于多个候选/条件作认证，需预定同时置信界或多重检验控制；逐候选 95% 界不自动构成整张选择表的 95% 认证。允许输出“无可行策略”和“统计不确定”。

最小性仅指声明候选内的最小复杂度，不指所有可能模型。简单候选通过选择规则，也不自动证明所有复杂方法都没有有意义的优势。

## 6. 统计判据：分别检验有价值、无实际必要和风险合格

令 Delta=C(new)-C(reference)，负值为新方法省成本。实际有意义的收益幅度 delta>0 须在新结果揭示前，以同一成本尺度和工程需求确定，不随测试结果调整。

- 强收益证据：单侧上界 U95(Delta)<-delta；同时报告原尺度和相对效应。
- 排除至少 delta 的收益：单侧下界 L95(Delta)>-delta。一个 p>0.05 不满足此条件。
- 区间跨越 -delta：尚不能判断是否有实际收益。
- delta 是新研究的效应解释阈值，不替换 E04/E07 的零容限，也不放宽 v_max。
- 成本收益与绝对风险资格分别判断；不能用其中一项替代另一项。

五随机种子仍保留，但同一测试期的五个种子不是五个独立风场。所有策略按同一时间块配对，重采样时同步保留机组空间相关与跨策略、跨种子的共同天气冲击；时间相关用预声明的连续时间块处理。块近似的相依/稳定性假设和敏感性结果全部披露，不宣称精确有限样本保证。

测试窗口长度根据开发数据的块方差、delta 和置信区间精度需求设计；不能直接假定35块足够，也不通过增加训练种子替代新增时间证据。正式窗口长度与结束规则先冻结，不反复查看显著性后决定何时停止。
