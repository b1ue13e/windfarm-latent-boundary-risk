## 3. 共同账本：等资源成立，归因尚不成立

### R04 / P1 — 强制花完会把分数尺度差异变成时序差异

**DERIVED：** 若两臂输入分数序列及初态完全相同，确定性的同一账本递推必产生相同行动和结果。因此账本不会凭空创造两臂差值；但是差值也不必来自更有用的状态信息。

手算反例（仅逻辑反例，不是模拟或新实验）：两个时段，单位时长设为1，共同B=1、上限1，真实短缺S=(0,1)。一个程序两个时段恒报0.8，另一个恒报0.2，二者都没有时间排序信息。V1投影使前者r=(0.8,0.2)、后者r=(0.2,0.8)，未覆盖短缺分别0.8和0.2。后者看似“同预算改善分配”，实际仅与强制末段花完交互。一个只用已知时钟的P-only策略r=(0,1)还能完全替代它。这里不主张实际数据存在这种模式。

**修复建议：**

- C1必须在预算任务中拟合并接受选择，覆盖尺度/下限/零点与截断次序；不是只在原任务校准后套账本。
- 给P/Z同等、明确的剩余风险预测与预算节奏控制能力；记录投影前后动作、预算耗尽、下界强制采购和末段分配，按整块与预先规定的位置报告。不得删去末段后仍称相同整块预算。
- 在已暴露开发材料上预先确定块相位/边界反证和连续预算上限的比较职责；它们是未来开发工作，不在本轮执行。若收益仅来自人为边界，则缩为该控制器下的程序现象，不能归为测量增量。
- 精确花完是有意制造的统计控制条件，不能说是实际采购制度。实际资源通常是否结转、能否不花完、容量/爬坡/交付约束、时变价格，需要M12另证。若改成预算上限不必花完，R通常不再恒等，必须按真实R报告，不能混称等额采购。

不得通过确认期效果挑块起点、cap或预算数值；两个参考q的预算也需历史证明为不同、非退化的资源层级。相同cap对称并不等于它与两臂分数形状的交互没有影响。

### R12 / P1 — 动作账本可行，不等于风险要求可行

`0<B<K·dt·rmax`只保证能花完钱，不能保证存在满足V≤.10的策略。**DERIVED：** 在相同cap的简单层级中，若某些S>rmax，这些时格无论怎么分配都会出现严格事件；即使允许事后oracle，在N个计分时格覆盖至少`ceil(.9N)`格，也至少需要这些可覆盖格中最小的`ceil(.9N)`个S的dt加权和。总资源低于这个下界时，甚至事后分配都不能实现该经验覆盖；逐块约束只会更严格。这是有限样本必要条件，不是对未来真实概率的可行性认证。

**修复建议：** 在已暴露历史中先审计风险可行性与非退化支持，不能只审计账本容量。新确认若作这种oracle诊断，只能是预声明、事后的设计解释；不能用未来S设B、排除困难块或声称该oracle可部署。预算不足、cap造成必然事件、统计区间过宽和P/Z程序本身未达要求应分别记录。若只有Z风险合格而P不合格，V1严格配对主门仍不能宣布通过，但也不能因此否认受约束风险改善的可能性；更改研究责任必须在确认前新版本声明。

### R05 / P1 — 覆盖校准的强，不等于备用分配的强

固定R后，C差恒等于10U差。因此目标是安排资源以降低未覆盖短缺，不只是将事件率调到10%。在不考虑硬在线路径的静态松弛中，增加r的边际U收益为条件超越概率 `Pr(S>r | I)`（原子处用次梯度）。比较各时段边际收益需要对不同r的风险有判断；单个q=.90分数及其offset不足以保证这个判断。

**DERIVED。** 硬逐时账本的真正最优还取决于未来信息到达与剩余预算，不能将上述静态条件冒充完整动态最优定理。

DtACI的Algorithm2自适应的是预测集错误/分位参数，原文没有为本项目的延迟、clip、强制预算投影证明分配最优或成本CI覆盖。[JMLR原文§3.4、Algorithm2](https://jmlr.org/papers/volume25/22-1218/22-1218.pdf)。Conformal PID也显式包含预测未来分数的scorecaster，说明“误差序列可以预测”是需要挑战的已有路径，而非新增pitch自然胜出的理由。[原文§2、§3](https://arxiv.org/html/2307.16895v1)。这些是方法核对，不是重新做一次全文查新。

**最低修复：** C5从名称变成可执行定义：用全部合法无pitch上下文预测预算相关风险/剩余需求，以剩余E、m、时钟及该风险产生动作，并在实际预算损失/风险上历史选择；P/Z共享控制架构、搜索机会、动作范围与回退规则。可用一个小型条件尾部/多分位程序或直接预算决策程序承担此责任，选择一种即可，不要求再建大模型。单纯将DtACI输出送入clip不满足这一条。校准器可以诊断覆盖，分配器须诊断目标U/C。

## 4. 统计、人口和主张仍有的漏洞

### R06 / P1 — 单机层和组合层尚未给出完全可复现的资源与信息定义

38行矩阵按两层重复，不说明单机层的B是逐机相同、逐机B_i，还是总B_G再分配；也没有规定组P-only如何使用21台向量、滞后、ID/位置，组Z如何加入对应pitch。组策略直接拟合S_G是正确方向，但单机与组策略的资源总和可能不同，不能只因都叫预算就比较跨层绝对收益。

**修复建议：** 冻结每层输出维度、控制权、成员、B_i或B_G生成规则、cap维度、计分分母和组特征映射。各层内部P/Z等预算即可支持该层结论；若要跨层比较，另需总资源可比且目标定义一致。把所有no-pitch动态向量压成均值而让Z保留逐机结构也不公平。所有这些字段可先凭现有元数据写清，不需新测量。

### R07 / P1 — 共同完整块减少比较偏差，却不能代表原运营人口

21台×144格意味着一块至少要求3024个成员—目标时格并对齐当前三pitch/当前P/F。即使两臂同块计分，只要缺失与天气、停机、控制或pitch相关，结果仍只识别“记录完整块”上的作用。控制器全日历运行防止前向泄漏，不会消除计分人口选择。

**修复建议：** 预先声明条件人口，不外推全部运营；在历史资料上核完整块损失、缺失位置与已有可观测工况的关系，并冻结不看效果的资格规则。新窗口只做该规则的盲结构资格；不足即停止，不能换小群组直到有效。组主策略读取不了合法控制字段时，不能靠剔除这些困难时段伪造基线公平。

### R08 / P1 — 3214坐标是清单，不是推断有效性或精度证书

坐标算术可对上，但同预算R为代数恒等、C和U线性相关，跨族比较又重复。多重校正不必因冗余一定变差，但不能把冗余数量当作严谨性的替代。过去收益已被查看，历史选择族也未完整冻结。DtACI的累积状态、8条交错流和硬账本均影响损失依赖；固定过去状态后仅重采样损失，是否支持期望中的跨天气参数，需要单独论证。

**修复建议：** 先定义估计对象（固定实例、哪些天气分布、条件于哪个可计分总体），区分独立坐标与派生守门；维持原alpha与效应阈值，不直接更换现有族。若下一版采用分层/闭合检验或更小主族，必须在新确认前写清，不事后缩族。长记忆或非平稳性不能用挑一个较长块长“解决”。Jan—Apr只有120个日历日，28日跨度约4个不重叠长块，缺测后更少；这只是日历上限，不能据此保证能检出1%或判定必定没有精度。M08没有完成就没有可宣布确认的统计资格。

### R09 / P1 — 替代与不可替代的证据责任不对称

V1的“任一强P复现则停止不可替代”正确；但“没有P通过替代”不足以证明“全部P已被排除”。风险区间跨10%也不能被当作P不可行。有限族反证里的“成本≤1%、H≤.001”还需要明确方向与分母。

**修复建议：** 相对Z的替代候选P，应检查成本溢价 `(C_P−C_Z)/C_Z` 的上界≤.01、每实例 `10(U_P−U_Z)/Cstar` 上界≤.001以及风险资格；主要增量比较仍按V1原方向。若要宣称该有限族不可替代，须对每个P给出至少一个相反方向的严格排除见证（风险下界超限，或溢价/缺额增量下界超过相应原容限）。证据不足者保留未解决。固定主P*的增量结论可以独立报告，但不得升级成全族不可替代。这里澄清方向，不改变阈值。

### R10 / P1 — 科学否证、研究不确定与停止投入应分别编码

| 状态 | 允许判断 | 不允许判断 |
|---|---|---|
| 来源/程序/账本/人口/推断资格失败 | 此确认无效或未具执行资格；停止该阶段 | pitch无用、P-only已足够 |
| 合格主比较收益上界≤1% | 本固定程序与任务不支持原重要差；不以次要胜者救主确认 | Bayes信息零增量、所有预算/场站永久无用 |
| 可信P替代见证成立 | 该有限任务中不可替代主张被推翻 | 所有状态测量均冗余 |
| 区间跨门限或竞争者未排除 | 未解决；不加算直到过门 | 无效、等价或独有信息已成立 |
| 同预算成立但原任务运行后果失败 | 受限分配现象可报告，当前TSTE主线不升级 | 受限现象本身被代数否定 |

“两层都通过”是V1较强的复合主张，不能确认后改；但它不是组合科学问题必然需要的逻辑。若未来选择以组合为主要、单机为机制，应在新确认前显式改版，保留V1的失败身份。较高预算“适用范围清楚”过于定性，应冻结具体边界主张/统计判据；区间不足就不作边界主张，不能靠一段顺耳解释补齐通过条件。

### R11 / P1 — 真实运行语义必须提前设上限

SCADA组功率之和不等于PCC，代理成本不等于现金，合成F不等于实际采购承诺。必须声明这里的r是外部补偿的账面备用，不改变风场P；若r代表控制风机本身，直接重放固定观测S不能识别该行动改变未来产出的后果。

**修复建议：** 当前只研究固定S下的有限程序代理分配，r不作用于数据生成。真实时钟、控制字段到达、外部资源容量、价格与交付语义由M07/M12另证；材料缺失应缩主张，不把它们作为改善网络可以填上的洞。TSTE关注并网可持续能源系统的设计、控制与评价，但未规定本文1%门槛或必须具备现场市场试验。[官方范围](https://ieee-pes.org/publications/transactions-on-sustainable-energy/)。因此不因缺真实市场价格直接宣判问题永远不适合TSTE；也不能只靠合成预算一个胜点就宣布够该刊。
