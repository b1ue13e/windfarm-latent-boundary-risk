# 回到现有事实：输入、目标与结果矛盾核查

2026-10-20。本轮只读现有源码、协议、报告和已派生结果；没有执行模型、统计计算、实验、采数或远端访问。使用 research-skill 的证据链核查，不重开选领域流程。

## 最值得解释的事实

**直接使用新增后果信号具有明显的可实现成本收益，但由同样信号重建的连续桨距角虽然准确得多，其额外决策收益很小、不稳定，而且尚未隔离出桨距角语义的特殊价值。**

与之相连的第二个矛盾是：低资源策略可以通过事先声明的平均成本非劣和二元风险门槛，却仍增加未覆盖短缺量。这不是结果互相冲突，而是不同评价对象回答不同问题。

据此可提出一条待讨论的主问题：

> **固定预测承诺和未来短缺目标后，新增遥测究竟减少了哪类备用决策错误；为什么更准确地恢复桨距角，不必然带来相应的增量决策收益？**

这句话是由现有矛盾引出的研究问题，不是已证明的机制、已认证的新颖性或启动实验的授权。当前还不能把收益归因于均值修正、尾部形状变化、控制状态或单一校准机制。

## 五组可靠数字

### 1. 新增信号改善成本，同时提高事件频率

WTB 开发窗口、缺 pitch 条件，A/B 平均损失为 **35.563052 / 32.828688** kWh等价/有效风机区间，B−A 为 **−7.6888%**；配对主3日块、42比较家族近似区间为 **[−4.852907,−0.837085]**。观测违反率却从 **10.1479%** 升至 **11.5666%**。

来源：`analyses/decision_information_execution_20261018/REPORT.md` §2；`key_comparisons.csv`；`evidence/results/aggregate/summary.csv`。

含义：指定有限拟合流程利用新增信号取得平均损失收益，不能称风险/成本全面支配或已通过10%资格。不是纯信息价值与估计误差的分离。

### 2. 测量恢复显著改善，附加决策变化很小

全后果探针与基础信息探针的连续 pitch MSE 为 **52.248969 / 387.906345 degree²**，下降 **86.5305%**。C−B 平均损失仅下降 **0.2071%**，主区间 **[−0.171425,−0.004112]**；仅3/5实例成本下降，1日块区间跨零。C相对基础信息分数、打乱标签分数的主区间均跨零。

来源同上 §2。这里既不能写“完全无收益”，也不能写“pitch语义独有、稳定、必要”。连续三叶片角度均值是测量标签，不是独立认证的物理控制状态。恢复指标与损失差不能直接当因果中介分解。

正面边界也必须保留：额外获得真实当前pitch的D诊断，在缺pitch下相对B成本 **−0.4032%**，在60分钟合成延迟端点为 **−4.0850%**，后者主区间 **[−3.288516,−0.297115]**。端点的B连W/P/Q及历史pitch都迟到，D却额外获当前pitch。这不是“真实pitch普遍无用”的证据；跨条件幅度差也不是已经检验的交互效应。

### 3. 开发集识别困难不能当信息必要性

更宽输入格的最终WTB结果：主3日块、2%容限 **28/28 案例都有风险合格策略，但0/28识别充分候选**；420个共享数据的案例中 **0个识别有限族最小性**。360k下 P1/PQ1−1 为 **+2.9615%**，联合近似区间 **[−2.2175%,+8.1405%]**；不能据此证明Q必要，也不能证明P1在5%内。

来源：`analyses/claim_revision_recovery_20261019/REPORT.md` §§1–3、`derived/summary.json`。指定的 `analyses/information_subset_execution_20261019/REPORT.md` 是执行中快照，不能将其“未完成”状态当最新结果。其最终WTB结果在上述回收报告；后续独立确认另行覆盖Towie状态。

### 4. 独立年主要确认通过，但不是成本胜出或选中全族最小

Towie2025，历史冻结 P1/HGB/q.95 与 WPQ36/HGB/q.95 成本为 **67.020403 / 66.644430**；相对成本 **+0.5641%**，主联合近似区间 **[+0.3575%,+0.7708%]**；两者最大实例风险上界 **6.2025% / 6.2004%**。这是相对冻结参照的2%平均成本非劣。

预声明全q次要分析识别的是 **P1/HGB/q.925**，成本 **65.739232**、最大实例风险上界 **9.7699%**，排除全部15个严格更小候选；主确认 q.95 **不在全q族2%充分集合内**。

来源：`analyses/independent_confirmation_execution_20261019/derived/summary.json` 与 `REPORT.md`。不可用次要q.925替换主要q.95，也不可据此回填原WTB失败。

### 5. 通过二元风险门槛仍掩盖短缺量差异

同一Towie主要比较，P1−全量的二元违约率为 **−0.0020392个百分点**，采购代理为 **−0.002890482**，未覆盖短缺代理为 **+0.037886336 kWh等价/有效区间**。未覆盖短缺均值增加 **2.184349%**，五个实例差值均正。加权后总损失净增加 **0.375972876**。

来源：`research_audit/14_resource_loss_break_even_review.md` §4；`research_audit/resource_loss_ledger_20261019/derived.json`。

含义：次数与短缺量不能互相替代。这是已有点记账，不是新显著性检验、极端尾部分布检验或物理因果解释。2%是研究容限，不是实际运营者认可的损失预算。

## A/B/C、P1/WPQ36究竟比较什么

共同符号：issue 为备用决策时刻，每步10分钟；共同点预测F名义发布于issue−6，使用截至该时刻的W/P历史，预测issue+6的有功。短缺目标 **S=max(F−P(issue+6),0)**；动作R非负；原记账 **C=(R+10·max(S−R,0))/6**、违反事件 **S>R**。有限零/负未来有功保留，不按pitch状态筛目标。

依据：`scripts/run_decision_information_development.py:181`、`:282`；`windfarm_moe/decision_information.py:48`；`scripts/run_independent_confirmation.py:251`。

| 比较 | 决策层输入 | 训练/标签与时间边界 | 可以怎样比较 |
|---|---|---|---|
| A | Common四列：F、issue时钟sin/cos、机组ID；加已到达W历史。pitch可见条件还加已到达pitch历史 | WTB同一共同预测/目标、同历史区段及种子抽样；缺pitch才是wind-only遥测 | A/B/C同一条件可配对；A跨信息条件并非始终同一输入集 |
| B | A加P/Q历史；缺pitch为W/P/Q各36个时槽；合成延迟造成末端未到达槽位缺失 | 直接HGB分位数拟合S；名义q.90，第一轮历史全局offset | 相对A是指定流程的增量输入价值；不是只用风速分箱，也不是原GNN |
| C | B加一个由B预测的当前连续pitch分数 | 探针在更早不重叠阶段用历史真实pitch监督；当前分数由已到达B确定 | 与B的运行信息相同；增量来自额外表示/历史监督/有限学习流程，不能称新增现场信息 |
| P1（缺pitch） | Common四列＋当前P，一共5个原始输入 | HGB/MLP直接拟合S；q标签表示历史offset档位，不是每档重新训练一个分位数网络 | 只称备用层新增当前P；共同预测已用W/P历史，不能称端到端仅用P |
| WPQ36（缺pitch） | Common四列＋W/P/Q各36观测，共112个原始输入 | 与同轮P1共享目标、掩码、样本及冻结offset制度 | 信息集合与旧缺pitch B同类，但不是相同拟合模型/选档程序，不能直接把数值拼起来 |

精确列规则：`windfarm_moe/information_subset.py:19`；首轮 `scripts/run_decision_information_development.py:192`、`:295`、`:313`；确认公共特征 `windfarm_moe/independent_confirmation.py:22`。

延迟条件额外注意：history/lookback限定在共同issue−35至issue窗口内，不是为迟到策略向过去多取数据补齐；P1表示最新已到达P，且pitch可见压力条件所有直接模型共享pitch历史。fresh/delay里的P1并非只有P。E压缩输入虽然仅A加分数，但生成该分数仍需B；不能虚构现场P/Q采集被取消。

## 哪些能够跨任务比较，哪些不能

1. 首轮A/B/C与风险—成本前沿沿用同一新WTB预测目标和已拟合模型，可联系解释；**offset窗口/选档改变了动作**，第一轮全部calibration的q.90动作不是第二轮历史选档后的动作。
2. 信息子集研究沿用WTB共同预测/未来目标，增加更小输入和第二估计器/预算；它可检验先前“B全部输入必要”的推断，却改变候选族和联合比较族。8,400坐标与252,500坐标结果不是同一个实验反转。
3. Towie沿用任务定义和程序结构，但场站、时间、样本量、天气覆盖、上游点模型和拟合参数实例均改变；2023/24重新拟合，2025独立确认。因此不能用绝对损失32与67比较场站难度，也不能把识别差异唯一归因为样本量或控制机制。
4. 新任务不是原E04共同预测及残差任务，不能把A/B/C新数值拿来解释或推翻原E04无可行结论。旧posterior模型C与此处C_PitchScore也不是同一个模型。
5. 所有时钟为声明的离线两馈送结构：上游预测用新鲜W/P，备用层才施加延迟。没有真实发布/到达日志，不提供端到端遥测故障因果或部署可用性证据。
