# V2 严格对抗审查：主张、对照与停止规则

日期：2026-10-19（Asia/Shanghai）。审查对象为提交51429268中的[PLAN_V2](../PLAN_V2.md)、主张表、矩阵及23项未定清单。

**结论：NEEDS_REVISION / NOT_READY_FOR_EXECUTION。** V2比V1可审查，但“矩阵有格、主张有ID”不等于识别链已经闭合。本次发现8项应在冻结前处理的重大问题，以及3项规格/一致性问题。这里的反例是数学或设计反例，不是本项目新实验结果。

采用research-skill；本报告为同一主智能体的再审，不冒称独立审稿人共识。未训练、推理、模拟、重采样、采数或访问远端。V2原文、23项状态和论文保持原样，仅增加审查意见和修改建议。

## 1. 哪些结论应保留

- 已查看2025不再充当新确认数据；q.95主要确认和q.925次要有限族最小性不能互换。
- 共同预测、目标、计分人口、到达信息必须对齐；P-only仅指备用层增量。
- C1全局效应与C2条件效应并列，不能因总体均值接近零便否定异质性。
- g使用向前样本外损失差；规则与阈值在新确认前冻结；低收益用上界而非不显著。
- 风险、损失、短缺严重度分开；组内证据与完整切换策略资格分开。
- 原始失败和UNKNOWN保留；不得以补方案为由恢复执行。

## 2. 八项重大问题

### R1｜C1能证明胜过历史选中者，不能自动证明胜过强P候选族

**定位：**V2第3节C1，第4节历史选择；PLAN_V2.md:58、81。

**反例：**历史选P_A而没有选P_B；新窗口中X胜P_A，但P_B胜X。即使C1及X_j−D_j部分通过，仍不能宣布额外遥测优于所声明全部强P备选。历史选择误差和漂移都可能产生这一情形。这不使预先冻结的P_A对X比较失效，问题在于“强P之外”的范围。

**修改：**默认采用窄主张C1-F：相对一个预先选择的P策略的程序增量；三组C1M也分别限各自历史冻结配方。“全部强P候选之外”的C1-FAMILY若要保留，必须另列有限族成本/风险联合比较，处理风险资格不确定的P候选，不能只排除点风险高或未通过上界者。不得测试后换P参照；也不必为窄主张强行扩大全对全检验。

**通过定义：**C1-F沿原配对判据；C1-FAMILY必须有事前完整候选和联合判据。历史赢家被称作“当时选择的参照”，不能称真实最优参照。建议核心只承担C1-F。

### R2｜C2A的简单基线不够强，MSE改善也不等于适用边界更好

**定位：**V2第3节C2A和第6节规则表；PLAN_V2.md:61、105—109。

**反例一（对照）：**真实条件均值g*=a(age)+v(vol)。同时使用两变量的G-FULL可以击败age-only和vol-only，却没有发现超越简单加性组合的规律。逐一击败单变量模型不足以支持“超越简单规则”。

**反例二（终点）：**G-FULL只在中间未判断域改善收益幅度预测，真正用于高/低判断的组与简单模型完全相同。C2与C2A都能通过，但不能声称高低适用边界优于简单规则。MSE本身是合理的条件均值预测终点，错误是将其扩大解释为更好的决策阈值。

**修改：**把G-AGE+VOL（低自由度加性）列为核心强简单参照；可再用相同廉价z的正则化线性均值模型检验额外非线性收益。参照的复杂度与正则化只在历史选择。C2A改称“条件平均收益的额外预测能力”；若要声称边界更好，另比较双方冻结分组的实际收益、覆盖、弃权及组均值预测校准，不能在测试侧强制相同覆盖来制造优势。不声称边界优越则不强制增加在线策略实验。

**技术限定：**配对平方误差差可写成2d_bar(g_full−g_simple)+g_simple²−g_full²，d_bar²项抵消。因此不能机械要求d_bar的四阶矩才能比较该差；应直接界定这个配对统计量的矩/尾部假设及推断适用性。

### R3｜g跨fold混合不同策略对，其边界可能是学习程序变化而非遥测条件

**定位：**V2第4节g标签、第6节最终refit；PLAN_V2.md:83、101—103。

**反例：**早期小训练窗选出弱P与强X，后期更大训练窗选出强P与另一X；同时天气波动随季节变化。g用波动预测d，实际捕捉了模型切换/训练量差异。最终冻结策略在一个新年通过，只支持这个最终策略对的条件规律，不能识别跨策略的一般遥测边界。

**修改：**建议核心采用事前固定的配对学习配方（架构/调参和校准选择算法一致），尽可能固定训练窗口长度/预算，向前重拟合产生标签；历史“最佳程序”比较作为另一条C1-F。若保留原选择程序路线，必须记录并分析fold的训练量、recipe/offset切换、是否无选择，表述为“该选择程序的收益预测”，不能混写信息属性。该路线与固定配方路线须在新开发前二选一，不能从结果中选更漂亮者。

**停止边界：**若收益预测主要随配方切换而改变，不能认定纯工况机制。确认一次固定对通过不会自动验证整个反复训练—选择程序的重复表现。

### R4｜风险资格前置可能漏掉“只有新增信息策略可行”的条件

**定位：**V2第4节无合格对不生成标签、第8节NO_HISTORICAL_CHOICE。

**反例：**困难时期P族没有通过历史风险上界，X通过。当前规则不形成对、不生成d，g只学到容易时期。即使报告无选择比例，也不能据此回答困难时期额外遥测是否有价值。P没有通过上界也不证明P真实风险超标。

**修改：**将“风险合格双方之间的成本收益”与“风险可行性差异”分开。可以保持C1只面向双方历史合格域，但标题、人口和C2支持域必须限定；预先选择一个诊断P回退可在无合格对时保留损失/风险信息，明确不认证为合格参照。若进一步声称X使原本不可行任务变可行，必须同时证明X合格和所声明P候选的失败下界，不能拿NO_CHOICE代替排除。

**停止边界：**no-choice不等于无收益；不得把它当效果为零，也不得为了补齐g标签提高风险cap。记录selection-status也是研究结果，不是可以静默删去的缺失值。

### R5｜完整14行不能自动保证公平；历史选择责任仍未落实

**定位：**V2第4/5节矩阵与调参；CONTROL_MATRIX_V2.csv。

**已核实实现差异：**旧HGB用常量插补及缺失指示；旧MLP使用训练均值/方差标准化与缺失指示。旧seed同时控制历史行抽样，线性算法即使确定性也不一定跨seed得到同一拟合。旧offset在clipped raw上求残差分位数。这些都必须进入新比较的规格，不能只列同样“历史offset”。

**漏洞：**P池有九个学习recipe加两简单策略，X池有三个recipe；搜索数、有限历史样本上的风险资格和误差分配可以影响谁被选中。不同池大小本身不必强求相等，但必须把每个实际比较/搜索自由度写清。给某一侧无限开发修补或只补输了的一侧也会破坏可审查性。

**修改：**先为每个j规定同输入/扩展对的同一数据索引、合法信息年龄/缺失元数据、独立历史调参预算与失败处理；插补/指示/缩放可以适合估计器，但差异透明。明确C/I/D/X为嵌套信息层：D必须保留I的最后P及年龄等合法信息，X保留D全部信息；不能把年龄或mask随数值通道一起偷偷删改。历史选择的风险上界应覆盖实际搜过的recipe/q/超参数族，或者有独立资格段；不能用最终确认的多重性处理倒补历史资格声明。历史资格可不作正式概率认证，但应相应降低其措辞。

**验收规格：**一张列到fit/calibrate/tune/qualify/select、seed、行索引和搜索次数的配对清单；新确认只检验历史冻结对可以是窄族，但这不认证历史赢家最优。确定性控制仅在实际输入/数据身份相同时共享，不按算法名字决定缓存。

### R6｜跨profile比较及未见age的学习对象没有闭合

**定位：**V2第2节仅保证fold/profile内F固定，第4节每profile分别拟合，第6节g含age，第7节不启用跨profile汇总。

**反例：**若每个profile分别拟合g，age在其中可能是常数，age-only只是组内常数；若g跨profile汇合训练，profile样本权重、共享天气复制和不同策略身份又未定义。若预留一个age，底层policy是否也未见该age没有说明，插值主张便可能只检验g的插值，甚至偷用了该profile的收益标签。

**修改：**在共同天气窗口中固定同一F/S跨所有压力profile，除非另立forecast任务。选择“每profile独立规则”或“单一跨profile规则”；后者绑定训练权重，避免同一天气反复出现被当额外独立天气。若只留出g的age标签而底层模型见过该age，明确称g的年龄迁移；若要声称整套程序未见age，底层模型也须有可执行的跨age输入/训练契约。缺少这项则删未见age主张。

**判断：**无需为当前窄范围主张强制做插值。但不能把可选插值写成一个空格之后就默认具备连续边界解释。

### R7｜推断对象、开发停止和严重度判据存在未闭合依赖

**定位：**V2第2/7节总体与天气推断、第8节A/B依赖上界而C稍后验证、第3节η_U。

**推断对象：**若目标仅是已观测固定全年有限样本，平均损失是确定性记账量；天气重采样区间需要另声明重复天气过程/未来同类窗口的目标。不能把“有限目标人口”与未定义总体的概率保证混用。季节/控制漂移的覆盖范围必须限定。

**停止反例：**未经验证的推断器在A阶段给出过窄上界，流程据此宣布“所有条件无重要收益”并终止，C阶段的推断验证永远不会发生。这会把不可靠区间变成科学否定。

**修改：**开发的继续/停投可使用描述性线索和预算，但标为研究决策而非反证；要科学宣称低收益，上界方法必须先通过相应C0适用性检查。开发规则反复选择的上界只属探索；独立确认才能承接正式主张。预先设最大轮数和固定总预算，不以显著性决定追加天气。

**严重度缺口：**η_U的U尚未精确定义。建议默认U=E[(S−r)+]Δt，即无条件未覆盖短缺，不是E[S−r|S>r]；后者可能因事件率下降反而上升。事件率、无条件短缺和尾部极值分别报告。C1可同时要求成本和U约束，但这是一个明确的多目标研究选择；η_U=0不应冒充业务标准。

**额外限定：**C0只验证固定策略/固定g的推断，不能顺带认证完整训练选择程序的重复表现。MC容差与旧风险cap分开，不能调大容差让欠覆盖“通过”。

### R8｜C2R、五实例平均和“适用建议”的措辞仍可越界

**定位：**V2第2节d_bar、第3节C2R、第9节O1。

**反例：**五实例平均成本有收益且五实例事件率均合格，仍可有某个实例成本变差。平均动作的风险也不等于各实例风险平均。g对平均d的预测不能直接说明任意一个待部署模型都有收益。

**修改：**明确主终点是五固定策略对的平均表现，不把它当ensemble动作或随机训练算法总体。逐实例成本差及符号须报告；若希望对每实例作建议，应增加相应同时下界，不用平均掩盖。C2R改称“固定分组中的风险/严重度检验”；只要读者将其执行成逐时选X/P，即触发O1。高低两组约束还不涵盖中间/域外弃权的实际回退。

**判断：**现有五实例平均估计对象可以保留；需收窄应用句子，不必自动要求五实例都显著。

## 3. 三项规格与一致性问题

### R9｜预算不是必须把每个确定性拟合重复五次

60K(J+1)是按12recipe×5标签的名义上界，不是完整算力报价。若LIN每seed使用不同抽样索引，五次拟合不同且不能缓存；若相同输入、相同确定算法才可复用。Common在同一fold跨均匀delay可能完全相同，可按数据/算法哈希复用；是否相同需由时钟与输入定义决定，不预设。保留完整比较格不要求冗余运行。旧source已显示seed控制行抽样，因此不能直接删除五次LIN。

### R10｜未定项清单混合“研究选择、材料资格、拟合产物和禁用扩展”

23项不宜全用null并要求在P0一律关闭：g拟合权重和数据驱动分组阈值要在未来开发后才产生，O1/O2/O3当前不启用不应阻断核心；而重要差、搜索预算和资格规则须先于相关开发声明。把同一项拆成design-fixed、material-qualified、fit-produced、confirmation-frozen四个时点，不可要求未训练先有权重，也不能等看到开发效果后才选择重要差。

逐项见[23项分流表](OPEN_ITEM_TRIAGE.csv)。11项可以现在固化规格或关闭其核心范围，12项需要补材料/分析产物才能完整判断；这不表示11项已经有经验真值或已获执行授权。

### R11｜V2的文献角色描述存在可直接纠正的不一致

V2第12节说“当前矩阵有mainstream/adjacent”“不填造foundational/failing”，但现存literature_matrix.csv已将von Kleist等记录标为foundational。本轮直接读取核实，无需新检索即可纠正为“已有foundational/mainstream/adjacent；没有经核实的failing记录”。不能为了凑四类补造失效论文。新颖性仍未穷尽核验。

## 4. 修改优先级与最小可审查版本

**先改估计对象和主张，不先填数字。**

1. 将C1改为对历史选定参照的C1-F；完整强P族优势可选，不默认增加全对全成本。确定g是固定配方还是选择程序标签；建议核心固定配方，程序赢家另作C1-F。
2. 加入组合强简单规则；把预测均值改善与边界改善分开。绑定跨profile的F/S、规则训练方式、信息嵌套及资格失败域。
3. 精确定义风险和U严重度；将开发预算停止与科学反证分开；明确推断目标和模拟验证范围。三个可选扩展继续禁用。
4. 按分流表固化可决定的规格，留下确需材料的字段；只有材料与阶段条件齐全，才另行评估是否恢复执行。

无需当前追加GNN/MoE、市场结算、全族最小性或完整在线切换。对“方法是否公平”的正确修复是清楚的配对数据/选择责任与合理开发机会，不是自动堆满更多模型。
