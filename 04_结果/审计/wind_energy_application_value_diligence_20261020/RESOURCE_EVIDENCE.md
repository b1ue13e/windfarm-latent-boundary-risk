## 2. 112→5到底减少了什么

主比较双方公共列都是 forecast、sin(time)、cos(time)、turbine ID 共4列；P1加当前P，WPQ36加W/P/Q各36个历史值。因而原始 learner 宽度为5对112。对应功能资源 tuple 为 `[1,1,5]` 对 `[3,1,112]`，不是传感器数、FLOPs或全系统资源次序。直接源码：`windfarm_moe/information_subset.py:20–38`，`windfarm_moe/independent_confirmation.py:21–34,49–54`；V2正文85、91–99行已正确限定。

107个不被低输入 learner 消费的原始列包括备用层的W/Q历史及35个更早的P滞后。它们不等于107个物理通道。公共F已经由更早的W/P各36步历史产生；截至 issue−6 的W/P输入仍然需要保留。备用时刻的当前P仍需到达，不能因共同上游用过历史P就当作当前P免费或已到达。

`scripts/run_independent_confirmation.py:251–263`先调用 `features(...)`；后者21–29行构造 common4+W36+P36+Q36+pitch36，即148列 float32 矩阵，然后273行才取 `stage['X'][:, cols]`。训练298行是 `fit['X'][indices][:, cols]`，先构全宽索引拷贝，再选列。因此**当前执行路径实现了 learner 端选列，尚未实现按子集裁剪读取/全特征构造的流水线**。这是实有局部减少与未兑现全程减少同时存在的情况。

原始列与变换后模型列也不同：HGB由 `SimpleImputer(add_indicator=True,keep_empty_features=True)`加缺失指示，实际指示数取决于历史fit缺失；MLP源码明确拼接同宽缺失指示。确切HGB变换宽度不由5/112推出，本地又无权重本体，不作新加载取证。依据：`scripts/run_decision_information_development.py:203–212`、`windfarm_moe/information_subset.py:49–63`。

## 3. 已存资源差异及其责任边界

下列汇总数**直接引用旧 `resource_loss_ledger_20261019/derived.json`、`resource_ledger.csv`，本轮未重新计算均值、字节差或时间差**。本轮回读了10个对应历史metadata/manifest/receipt及10个evaluate receipt，核计时段、配方、节点和文件身份；源文件SHA256及字段见附CSV。worker按seed配对为8/42、53/87、98/132、143/177、188/222。

| 现有量 | WPQ36 → P1 | 已支持的局部价值 | 不支持的扩大推论 |
|---|---|---|---|
| learner原始列 | 112 → 5 | 模型输入规格更简单，少消费107原始列 | 实际传感器、全源数据或网络同比下降 |
| 360k行训练选列矩阵值体 | 161,280,000 → 7,200,000 B | 该选列表达式少154,080,000 B名义值体 | 进程RSS/峰值内存下降同幅 |
| 年度预测选列矩阵值体 | 494,418,624 → 22,072,260 B | 该选列表达式少472,346,364 B名义值体 | 在线报文大小、驻留内存或每调用流量 |
| 政策模型文件均值（manifest） | 424,229.8 → 190,357.8 B | 若存储/分发同一政策文件，本体少233,872 B，约228.4 KiB | 全部署包、内存模型或生产网络费用 |
| 共同点模型+政策文件本体均值 | 766,734.8 → 532,862.8 B | 共同点模型342,505 B不变，合计仍少233,872 B | 包括依赖、原始数据、日志等的全部系统存储 |
| 存档 `fit_seconds` 五实例均值 | 34.679387310240415 → 2.5003294139867647 s | 固定配方离线fit观测差−32.17905789625365 s | 受控硬件加速比、纯训练内核、计费或线上延迟 |
| 完整历史worker均值 | 42.531908 → 8.6652676 s | 该历史批处理步骤耗时记录更短 | 单次在线耗时或完整系统重训节约 |
| 完整全年evaluate worker均值 | 6.797192 → 5.3467248 s | 年度离线评估观测差−1.4504672 s | 纯predict延迟、P50/P95或吞吐上限 |

矩阵值体是旧报告从表达式、float32类型和现存shape得出的确定性名义尺寸，不是此次读取大数组或内存测量。148列共同X的旧名义值体为653,338,896 B，两策略相同；第一份360k行全宽索引拷贝为213,120,000 B，两者相同。选列数组本体减少是真实可说明的局部实现后果，但不能直接把它与“完整矩阵仍存在”相减为进程峰值。

模型文件数据的证据层级是**原执行manifest记录**。例如seed201，`historical/8/manifest.json`声明P1模型190,361 B、SHA256 `6f28e2422b2d34018cf4a6b66eb2820ba5a513c52d0042f683069db6cdbec20d`；`historical/42/manifest.json`声明全量424,233 B、SHA256 `5bce19b39ace1c2dadc70f5660189e0e68b396ed87484174e18a6046004c82f3`。本地10个model.joblib均未找到；这些hash不是本轮读取权重后独立核验的值。小文件的局部好处成立在该存档记录层级，不能说本轮测量了内存模型或生产分发。

## 4. 计时有多少可比性

**已核实的匹配：**同一HGB配方、100迭代/最多15叶/min_leaf50、360k训练行、相同目标与seed，五对 `fit_indices.npy.sha256` 均相同。Python3.11.16、NumPy2.4.6、sklearn1.9.1、Torch2.11.0+cu128、Linux平台字符串与CPU-only backend记录相同。historical/evaluate PBS请求均为2 CPU、16GB，并设置OMP/OPENBLAS/MKL线程上限2。前述匹配使“同固定算法recipe中低输入实例离线fit观测更短”有实质依据，不能全抹成噪声。

**未匹配/未测部分：**五对历史worker不是同一节点的交替受控计时；例如seed201 P1在cn28、WPQ36在cn13，seed202为cn13/cn21，其他对也不同；任务起止区间互有重叠。CPU型号、节点负载、每recipe实际cput、RSS、能耗、账单未绑定。CPU-only receipt不因Torch带CUDA build而成为GPU实验。2CPU/16GB是申请额，不能作实际消耗或节约额。

`fit_seconds` 在 `time.monotonic()` 的297–299行包住 `model.fit(fit['X'][indices][:,cols],...)`，也涵盖该调用的取样/选列实参求值；不包含更早的完整148列构造或上游点预测。故可引用真实记录，不能命名为纯计算内核benchmark。完整历史worker还包括校验、特征、offset、选择和写出；完整evaluate的482–522行包括校验、加载、148列构造、预测、五q记账、独立一致性校核与压缩写出。后者不是在线预测接口计时。

**INFERRED：**少列很可能降低该固定HGB recipe的部分fit负担；但“可复现的受控加速量”“更低生产成本”仍未知。无需为说明这一界限自动安排新benchmark。

## 6. 有正代价时能否算“值得”

现存 `loss_ledger.csv` 的主比较记录：成本均值差+0.3759728759822849 kWh-equivalent/有效机组间隔；`derived.json:deltas_p1_minus_reference.relative_cost` 为+0.005641474815992087；旧评审记未覆盖短缺点均值增加2.184349%。原主检验的合格身份保留，次要q0.925不替代该主比较。本轮只引用现存数，不新增严重度区间或统计检验。

如使用者拥有一个经绑定的资源价值函数，代数接受条件才可能写为 `避免的资源价值 ≥ 同一业务口径下新增后果价值 + 实施切换成本`。这只是必要的对账形式，**不是实测盈亏阈值**：当前左侧的资源价格/取消条件和右侧代理到业务价值的映射都未知，不能填入假设电价、费用、训练频率或维护工时。也不能拿32秒或233,872 B去抵398,248.517年代理单位。缺共同单位时，两边是不同量纲的向量，而不是可合法相加的净收益。

这里存在的直接学术价值是：在有冻结历史程序、共同预测/目标和完整负结果的受控实例中，量化少输入recipe保留哪种资格、付出哪些后果，以及有限族最小性与主确认的差别。这可以作为可信的经验记录与复核资产。资源证据**尚不能**进一步给出“风电使用者为什么应在这个接口采用这种交换”的答案；当前未识别的也不只是缺一张资源表，而是约束、可取消边界与后果价值三者未接通。
