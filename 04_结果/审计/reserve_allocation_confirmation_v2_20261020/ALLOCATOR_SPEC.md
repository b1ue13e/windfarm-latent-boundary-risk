# C5：预算任务内的强无pitch分配器规格

这是未来实现规格，不是已经实现/运行的代码。现有模型未被重新拟合。以下结构已落实；剩余计算参数列明，不用预期结果填空。

## 1. 预测对象与信息

每层、每臂、每固定实例预测一组条件超额损失曲线：

`g_t,j(a) ≈ E[(S_(t+j)−a)+ | I_t]`，j=0,…,143。

I_t为PLAN规定的全量合法上下文；加入j、未来已知UTC正余弦/块位置、层级/成员ID。未来未知天气、未来F/功率/pitch/可计分掩码均不是输入。即使未来某F在历史文件可查，也不当作t时已知输入。目标S_(t+j)可以作为历史监督标签，但只有全部相关标签成熟后才可训练/更新。

Turbine池化逐机训练，含固定ID；Group按固定21ID拼接完整无pitch向量及共同组上下文，两臂同等；不能P仅均值、Z保留逐机结构。零/负未来P保留，S取正部，缺目标不插补。

原点预测F和基础分位分数仍可在同身份时复用，但该超额损失模型是**新增学习器**，不是加载旧q=.9权重就已具备，也不是本论文新算法主张。

## 2. 历史学习与曲线约束

动作节点固定为 `a_l=(l/16)cap`，l=0,…,16。这是数值控制网格，不是更改统计或科研阈值；确认后不增密追效果。每节点回归目标 `(S_(s+j)−a_l)+`。

用HGB平方误差学习 `g_fit(I_s,j,a_l)`；名义参数沿用现有HGB容量（100迭代、15叶、最小叶50、步长.08、L2=1、无early stopping），五实例201—205；训练内常数0插补+缺失指标，缺失不使用未来填补。两臂共享合法监督三元组(s,j,l)与拟合行身份，最多360000三元组/模型，按固定实例种子在共同历史资格集合均匀抽样；不在Z有效较多的行另加训练机会。若有效三元组不足则取全部并记录；支持不足不声称模型已合格。训练截止满足 `s+j+7 < 下一阶段首issue`。

对每条17节点预测作唯一的欧式投影，约束：g≥0，分段斜率在[−1,0]，且斜率随a非递减。得到非增凸的分段线性超额损失曲线；**不强迫g(cap)=0**，因为短缺可能超过包络。严格凸投影目标保证节点解唯一，求解精度/软件版本须未来测试冻结；失败不能静默取零曲线。

## 3. 自适应残差校准

保存每次合法过去issue s对各j/l的曲线预测及其当时上下文。等 `s+j+7<t` 后才能计算残差 `e_s,j,l=(S_(s+j)−a_l)+−g_fit(I_s,j,a_l)`。

以**预测issue时间**落入最近w个日历日且标签已成熟的记录，计算各j/l平均残差b_t,j,l；w∈{7,14,28}是历史选择候选，含零修正的静态版本为嵌套候选。Turbine按固定成员池化成熟误差，Group按组记录；P臂只用自身预测残差，不读Z预测/误差/预算。无成熟支持时b=0并记录fallback，不向未来或训练拟合内补误差。最终曲线是对 `g_fit+b` 再作上述形状投影。

状态预热必须使用冻结学习规则在拟合外7月顺序进行；选择段按实际日历流和成熟时钟继续更新。确认若未来存在，也只允许冻结规则的成熟反馈，不允许人工看累计效果改w或重训。在线曲线变化不借用DtACI的覆盖保证；C4单列DtACI比较，不把两者混名。

## 4. 每步滚动预算优化

在当前t，剩余m格、预算E、共同cap，解：

`min Σ_(j=0)^(m−1) dt * ghat_t,j(r_j)`

`s.t. 0≤r_j≤cap, Σ dt*r_j=E`。

g为凸分段线性，故是有限凸优化；可用线性上图形式表示，不需要未来真实S或未来分数。若最优解不唯一，先固定最优目标值，再在最优解集合内最小化 `Σ(r_j−E/(m dt))²`，取得唯一确定性解；不通过任意epsilon混合目标改变主损失。数值容差属于实现测试，不能转成新的科学等价阈值。

只执行r_0，用共同可行账本复核与记账；下一issue用新I_t和自身E重解。当前r_0已经满足lo/hi；因数值偏离需投影时记录前后差，超原记账精度则实现失败，不假装严格最优。回放反馈用实际投影后动作。

计算失败的预声明动作回退为 `r=E/(m dt)`（在合法E范围内可行），继续记录；不得看未来决定回退。未来历史须验证非故障运行；发生回退的确认数据不能偷偷删除。频率和原因全部报告，不能把严重故障包装成C5正常策略效果。是否有足够方法资格须在新确认前决定，不新增事后故障率门槛。

当前预测量包括未来j处的**条件期望风险**，不声称观察到了未来输入。反复重规划是可实现启发式；不是完整随机动态规划/Bayes最优证明。

**全日历缺失职责：** 仅历史槽按拟合内插补规则处理；若当前必需P/F或Z臂当前pitch不可用，该臂当步不把缺测硬当正常输入：预算任务走U0，RAW走冻结历史无pitch参考的同月平均速率。该臂该步对应的曲线预测记invalid，不拿它补造未来校准残差；其余合法既往预测仍可在成熟后更新。是否未来整块可计分不参与此判断。全部家族采用相同的合法缺失/失败规则；不能读取另一臂动作或用未来目标完整性决定回退。此为需要未来实现/测试的规则，本轮未执行。

## 5. 必需对照、选择与RAW版本

- U0：每步 `E/(m dt)`，同预算、同cap，不读Z，防止只胜过强制末期花完的弱控制器。
- C1：在预算任务损失上历史选仿射/floor配置，防止尺度差假装时间信息。
- C0—C4：沿V1各族，在实际共同账本后的C/V上选代表，不用原无预算最佳代表代替。
- C5-P/Z：同一结构与候选w；各自历史选最优，监督三元组/容量和选择机会相同。
- IGNORE_Z：整条程序精确复制该任务P赢家，包括其初态、成熟状态、预算规则；若两条流均忽略Z，账本与动作应逐时相同，未来须有身份/动作测试，不以样本零方差推断。

RAW恢复原非负且无账本上限的动作域。C5在a≥cap处按最后一段斜率v≤0作 `g_ext(a)=max(0,g(cap)+v*(a−cap))` 的固定凸非增延伸，cap内用原曲线；该延伸是预测程序假设，不声称真实尾部线性。按当期 `argmin_(r≥0){r+10*g_ext_t,0(r)}` 取动作，精确并列取最小r。目标在足够大r时随r增大，有限解可在分段节点及尾部折点取得；v=0时cap后无需增大动作。不能把实验cap偷偷施加给原RAW任务，或在看到后果后另改尾部外推。

无预算状态E/m不进入RAW。RAW自身历史选胜与预算历史选胜分开；预算所选C5导出的RAW桥接仍使用预算所选w/模型和同一尾部规则，不重新拟合或选择。

全部程序是代理任务。若真实采购按时变价格、备用容量/爬坡约束或跨日结转，必须另定义资源与价格；不能将本等额dt*r账本直接声称为真实采购金额。
