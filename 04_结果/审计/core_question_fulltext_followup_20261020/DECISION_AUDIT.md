# 对停止决定的第二轮短审查

2026-10-20。已重读治理文件、research-skill和`core_question_identification_20261020/DECISION.md`。沿用既有数学审查，不新增检索、测量、实验或统计计算，不改旧文件。

**裁决：停止旧的强主张是正确的；窄主问题仍值得按TSTE研究候选保留并推进研究判断，不等于恢复执行。** DECISION.md明确说全文缺失不证明对方已解决全部问题、窄问题并非没有价值，因此没有直接的逻辑矛盾。但若把其`NO_GO_FOR_CURRENT_TSTE_RESTART`扩张成“这个窄问题不值得研究”，依据不足：全文尚未到、效应未知和解释尚未完成，是信息不足及研究风险，不能单独替代对预期新知识价值的判断。要求一条尚未开展的研究先有完整运行与时间外证据，才能称值得研究，会混淆立项判断与成稿验收。

应停止的是“三种总体机制最终择一”“纯信息贡献占比”“pitch的物理先行因果”及现有结论已经够TSTE的承诺。值得研究的对象是：**在明确十分钟时槽、固定承诺/目标和匹配学习程序下，真实状态测量是否带来强后果历史之外的可实现前瞻增量；后果陈旧时，该增量能否由同样新鲜的功率替代。** 这有物理来源与时效含义，可被预定对照反驳；不是给V3的收益分组换名字。其价值取决于边界的可复现性，不能预设阳性，也不能预设负结果就不值得发表。

| 缺口类型 | 本轮判别 |
|---|---|
| 当前观测本身无法唯一确定 | 未测控制命令的因果效果、10分钟槽内事件顺序、无测量/缺失假设下的缺失真pitch、离观测支持的干预，以及任意未来漂移。应删这些主张，不把它们变成窄题的必补材料 |
| 需要结构假设而非仅多跑模型 | 广泛连续非参数类的统一有效CI检验；从有限程序胜负推纯Bayes信息值或遗憾分摊。总体对象可识别，但当前有限证据不具备相应确认条件 |
| 尚未实施、现有资产可处理 | 共同人口/缺失掩码核查、WTB逐时配对归档、Towie fresh与pitch-withheld的pitch36双估计器配对、明确成员的组合净短缺。无须先采新原始数据，实际结果仍未知 |
| 需要新分析但未必新原始数据 | 等时fresh-pitch/fresh-P对照、未来S的声明分布预测输出及与动作的连接。必须另获执行授权；不能将尚未实施说成无法研究 |
| 需要新确认资格 | 新解释的时间外验证。旧2025可做事后/开发证据，不自动保有新假设的独立确认身份；公开新窗口的存在也不等于已经合格 |

最少两项会实质改变当前判断的证据包是：

1. **直接近邻的完整责任比对。** 核到原文究竟有没有共同目标下的真实pitch增量、强后果参照、等时fresh-P替代及时间外边界检验。若这些核心责任已被完整承担且无实质新增，停止窄题；若存在明确未承担的风电边界责任，才支持新颖性。取得PDF本身不是通过。
2. **事先限定、人口和时效匹配的测量增量/替代证据。** 保留全部预定对照与实例，分别报告损失、违反次数、缺额量及不确定性；从旧档案核身份和人口起步，再按授权补缺格，并对提出的边界作未参与构造的检验。可靠的不可替代增量或有意义精度内的可替代边界都可以改变判断；不能只挑一个好看的工况或种子。若始终只能给出宽区间、任意分组或一般新鲜度叙述，不能支撑TSTE边界贡献。

这不是对两项证据必然取得的保证。我的正面意见是“有可识别的窄对象、明确资产路径及可反驳的知识责任，值得研究”，并非“已有证据证明必能发TSTE”。保留项目停止状态和空执行队列，与这个问题价值判断并不冲突。
