# PMU / 构网逆变器：数据优先选题审查

日期：2026-10-20。状态：`NO_GO_AS_TOP_JOURNAL_MAINLINE`。

本轮只读取公开元数据、发布说明和论文正文；未下载测量数据或 ZIP，未训练、仿真、运行实验、访问远端，未改论文或既有审计。目录内 PDF 仅供本地文献阅读，不是交付正文，也不应提交 Git。本文是选题判断，不是科研里程碑认证。

## 结论

**不把这一方向列入本轮优先立项名单。** 原文采用有控制结构定义的 dVOC EMT 模型，原则上可据独立原始模型定义模型内互联真值；但本轮没有从公开源码树核实原始详细 EMT 模型可取得，不能填作“完整基准已取得”。不应因为缺少实物闭环真值而否决一切理论研究。真正没有通过的是新知识门：当前能清楚表述的几条责任——高拟合不保证闭环保真、轨迹学习需保留特征值、有限带噪 I/O 的相容模型认证、非线性区域耗散、激励覆盖不足导致认证失败——都有直接先例。将这些责任组合后用于一个 GFM 数据包，尚未形成区别于既有结果的新定理或新机制。

此结论不表示“非线性端口辨识已全部解决”，也不表示“所有可能的 GFM 理论都没有价值”。它表示：目前不足以向用户推荐一条有明确新颖性责任、能通过既有材料闭合的顶刊主线；不应先承诺题目，再靠更换网络或损失函数寻找结果。

## 3. 唯一值得形式化、但本轮仍不推荐的对象

设端口记录为 D，声明的有限维 normal-form 类为 M_n，噪声/模型余项界为 E，电网互联参数为 z。构造相容集合 M(D,E)，寻找

`Z_cert = { z : 对每个 M 属于 M(D,E)，互联系统在声明区域内满足稳定证书 }`。

若能找到两个同样相容、却在同一 z 下稳定性相反的模型，则该 z 的稳定性**尚不可识别**；没有找到证书只表示未认证，不等于物理不稳定。小信号版本必须把共同旋转对称方向剔除后再判特征值；不能用稳定性代替故障恢复或额定能力。

这个定义本身只是把已知相容模型/鲁棒稳定思想写在本应用上，**不是新定理**。要成为真正新方法，至少必须提出并证明一个现有结果不能直接给出的命题，例如：在端口不可观测内部状态和已量化非线性坐标误差下，给出对互联域有效、严格改进现有通用组合证书的可计算条件。当前还没有这样的命题或推导；不能把“以后也许证明”当选题已过门。

三种方案的第一性原理后果：

1. **把 normal form 当精确模型类。** LTI隐块+已知非线性接口可研究，但先须说明为什么已有噪声I/O认证、IQC/耗散组合不能直接承担责任。仅换到电网参数域，很可能是方法应用。
2. **把 normal form 当 EMT 近似。** 证书必须包含其在整个认证域内的偏差界；独立响应拟合误差不能替代该界。若独立原始EMT模型资格闭合，可供模型内验证；目前模型源闭合和新证明均未建立，不能用已识别矩阵代替原始EMT真值。
3. **加入未激活的限流/保护来制造差异。** 现有温和激励没有辨识该模式，得到“未知模式不可由未触发数据认证”属于经典不可识别性，不是顶刊发现。

## 4. 四个问题与投资判断

* **Why care?** 逆变器模型若误判互联稳定，会影响接入/控制设计；问题重要。这不能单独证明选题值得投。
* **What's new?** 目前尚无可确认的新命题。拟合/稳定错配和数据认证已有密集先例，不能包装成首次发现。
* **Why believe it?** 若原始dVOC EMT材料闭合，可定义模型内真值，理论证书可以由公开方程与反例审查；目前原始源码资格未核。实物PHIL只提供有限响应检查。关键缺口是新命题、适用假设和原始模型来源，而不只是多跑实验。
* **Why this venue?** 若有新的、非平凡且可计算的端口互联认证理论，并证明其改变实际可认证范围，可能与TSG/TPWRS等读者相关。仅加模型或整理现有方法比较不够；此时不宜承诺TSTE或综合能源顶刊。

### 即使最理想结果出现，仍可能不新

在dVOC基准上发现：训练拟合R²很高但某个弱电网连接不稳定；加入耗散/Jacobian约束后能正确识别，并在另一个网络上更准。**这一结果仍可完全落入“原文开闭环差异 + LFI-NODE稳定特征学习 + 既有鲁棒耗散组合”的覆盖范围。** 数字很漂亮也不自动满足新知识门。

### 本轮停止条件已经触发

当前无法给出超出上述先例的明确新命题；最强现成贡献可被既有理论组合解释。因此不授权进入实验或模型开发，不把方向保留为默认候选。以后只有出现具体的新命题、证明路线和相对上述先例的严格差别，才构成重新评估的理由；不是先加噪声、再加非线性、最后加GNN来延长选题。
